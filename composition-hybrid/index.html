Vertiefung02

Kontext und gezielte Rückmeldung machen den Auftrag konkret

Die Werkzeuge übernehmen verschiedene Aufgaben. Workspace und Obsidian halten Quellen, Anforderungen und Entscheidungen verfügbar. Codex kann damit Inhalte und Code ausarbeiten und Werkzeuge einsetzen. Git und GitHub machen Fassungen und Bereitstellung nachvollziehbar. HyperFrames setzt geplante Darstellungen als Medien um. Die steuernde Arbeit wird am Recherchebeispiel sichtbar: Der Lernbogen verlangte eine eigene Auswahl, der Entwurf nahm sie vorweg. Die Korrektur setzte zwei echte Textauszüge vor die Modellentscheidung. Kontext geben, die konkrete Seite bearbeiten und den geänderten Ablauf nachprüfen greifen dabei ineinander. Die Vortragsanweisung ist eine redaktionelle Verdichtung, kein Originalprompt.

Vertiefung08

Ein formaler Abschluss bestätigt noch keine Lernwirksamkeit

Der adaptive Qualitätszyklus bindet Kriterien und Befunde an die geprüfte Dateifassung. READY_FOR_REVIEW bestätigt formale Abschlussbedingungen.
